# Подключение GetPlatinum

Делается один раз после деплоя, когда у сайта уже есть домен и HTTPS.

## Что нужно знать заранее

Я писал этот адаптер **без технической документации GetPlatinum** — их сайт
не открывался. Поэтому вместо выдуманных имён полей всё, что может у них
называться по-своему, вынесено в `.env`, а всё непонятное код не додумывает,
а останавливается и пишет в Telegram.

На практике это значит: первая оплата, скорее всего, потребует дописать
одну-две строки в `.env`. Сайт про это сам напишет и подскажет, что писать.

## Шаг 1. Ссылка на форму оплаты

В кабинете GetPlatinum возьмите ссылку на платёжную форму и положите её в
`.env`:

```
PAYMENT_PROVIDER=getplatinum
GETPLATINUM_FORM_URL=https://... (ссылка из кабинета)
```

Сайт допишет к ней номер заказа, сумму, описание и адрес возврата.

Если в кабинете параметры называются иначе (например, не `order_id`, а
`payment_id`), поправьте имена — код при этом не трогается:

```
GETPLATINUM_ORDER_PARAM=payment_id
GETPLATINUM_AMOUNT_PARAM=summa
```

## Шаг 2. Адрес для уведомлений

Придумайте длинную случайную строку — это секрет, по которому сайт узнаёт,
что уведомление пришло действительно от GetPlatinum:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Положите её в `.env`:

```
GETPLATINUM_WEBHOOK_SECRET=сюда-строку-из-команды-выше
```

А в кабинете GetPlatinum в поле «URL уведомлений» (может называться webhook,
callback, notification URL) укажите:

```
https://ВАШ-ДОМЕН/webhook/getplatinum/сюда-ту-же-строку/
```

Секрет прямо в адресе — это и есть проверка подлинности. Никому не
показывайте этот адрес и не выкладывайте его в переписку.

## Шаг 3. Первая оплата

Проведите одну настоящую оплату на минимальную сумму. Дальше один из двух
исходов.

**Доступ открылся сам** — значит, статус в уведомлении назывался понятно,
и настраивать больше нечего.

**В Telegram пришло «Уведомление об оплате, статус непонятен»** — в
сообщении будет список полей уведомления. Найдите среди них то, где лежит
статус, и допишите в `.env` две строки:

```
GETPLATINUM_SUCCESS_FIELD=имя_поля_из_сообщения
GETPLATINUM_SUCCESS_VALUES=значение_при_успехе
```

Например, если в сообщении видно поле `payment.state`, а при успешной
оплате там `CONFIRMED`:

```
GETPLATINUM_SUCCESS_FIELD=payment.state
GETPLATINUM_SUCCESS_VALUES=CONFIRMED
```

После этого перезапустите сайт (`./deploy/update.sh`) и повторите оплату.

Пока правило не настроено, деньги не теряются: платёж виден в админке, и
доступ можно выдать вручную — «Дела» → «Воронка» → карточка человека, либо
в админке отметить платёж оплаченным.

## Что сайт не сделает молча

- **не откроет доступ**, если статус в уведомлении непонятен;
- **не откроет доступ**, если сумма в уведомлении не совпала с суммой заказа
  (напишет в Telegram);
- **не откроет доступ дважды** по повторному уведомлению — подписка не
  продлится на лишний месяц;
- **не примет** уведомление на адрес без правильного секрета.

## Если появится документация

Когда у GetPlatinum найдётся описание подписи уведомлений, её проверку
стоит добавить в `payments/getplatinum.py` рядом с разбором тела — это
десяток строк, остальное менять не придётся.
