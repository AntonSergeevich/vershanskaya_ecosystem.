# 🌌 Vershanskaya Ecosystem (powered by S-Poryadok)

> Комплексная веб-экосистема и микро-CRM для эксперта Екатерины Вершанской. Платформа объединяет интерактивное обучение, управление подписками, систему бронирования и автоматизированную воронку продаж.

## 📋 О проекте

Проект разработан для автоматизации рутины, масштабирования бизнес-процессов и бесшовной конверсии трафика в постоянных участников закрытого клуба. Основной упор сделан на архетипическую упаковку смыслов и геймификацию пути пользователя.

### 🧩 Основные модули

1. **LMS & Платформа обучения (Smart Content)** — `lms/`
   * Три уровня доступа: Искатель (бесплатно), Творец (клуб), Маг (личное ведение).
   * Курсы делятся на разделы (`Module`), уроки можно открывать как превью.
   * Видео хранятся **вне публичной папки** и отдаются только после проверки доступа,
     с поддержкой перемотки (HTTP Range).
   * Прогресс по урокам и «путь героя» в кабинете.
2. **Квиз-воронка** — `quiz/`
   * По вопросу на экран, прогресс сохраняется (эффект Зейгарник).
   * Контакты собираются на последнем шаге, результат — архетип с раскладкой по весам.
   * Прохождение автоматически превращается в пользователя и лида CRM.
3. **CRM и воронка продаж** — `crm/`
   * Канбан-доска с перетаскиванием карточек.
   * Автоматика двигает лида только вперёд, руками можно и назад.
   * Telegram-рассылки по этапу воронки.
4. **Система бронирования** — `booking/`
   * 30-минутные окна, генерируются одной командой.
   * Захват слота через `select_for_update` — двойная запись невозможна.
5. **Платежи и подписки** — `payments/`
   * ЮKassa / Prodamus, вебхук с проверкой статуса через API.
   * Доступ выдаётся в одной точке (`grant_access`), повторный вебхук ничего не дублирует.
   * Без настроенного эквайринга работает ручное подтверждение — вся воронка кликается локально.

## 🛠 Технологический стек

* **Backend:** Python 3.11+, Django 5.2, Django REST Framework.
* **Database:** PostgreSQL (на локалке SQLite для быстрой разработки).
* **Frontend:** серверные шаблоны Django + один CSS-файл без сборки.
* **Авторизация:** Custom User Model (вход по телефону, Telegram ID).

## 🚀 Быстрый старт (Local Development)

```bash
git clone https://github.com/AntonSergeevich/vershanskaya_ecosystem.git
cd vershanskaya_ecosystem

python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env        # заполните SECRET_KEY
python manage.py migrate
python manage.py seed_demo --with-slots   # демо-контент: квиз, курсы, отзывы, окна
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000 — главная, квиз и курсы уже наполнены.
Админка: `/admin/`, канбан-доска воронки: `/voronka/` (нужны права сотрудника).

### Переменные окружения

Все секреты читаются из `.env`, полный список с комментариями — в `.env.example`.
Минимум для запуска: `SECRET_KEY`. Всё остальное имеет разумные значения по
умолчанию, а интеграции без ключей работают в режиме заглушки (пишут в лог,
ничего не отправляют).

### Фотография и тексты первого экрана

Портрет, заголовок, текст «обо мне» и подпись у фото лежат в базе, а не в
шаблоне: `Админка → Профиль сайта`. Запись всегда одна, создаётся сама.
Пока портрет не загружен, на его месте стоит заглушка того же размера —
вёрстка не «прыгает», когда фотография появится.

В заголовке первого экрана слова в `*звёздочках*` выделяются курсивом и
цветом. HTML оттуда не пройдёт: текст экранируется, теги расставляет фильтр.

## ⚙️ Команды управления

```bash
# Демо-контент (идемпотентно, повторный запуск ничего не задваивает)
python manage.py seed_demo --with-slots

# Окна для записи: будни, 10:00–18:00, по 30 минут, на две недели вперёд
python manage.py generate_slots --days 14 --from 10:00 --to 18:00

# Закрыть доступ по истёкшим подпискам — в cron раз в сутки
python manage.py expire_subscriptions
```

## 🔐 Защита видео

Видеофайлы уроков лежат в `PROTECTED_MEDIA_ROOT` — **вне** `MEDIA_ROOT`, поэтому
прямой ссылки на них не существует. Запрос идёт через `lms.views.lesson_video`,
который сначала проверяет уровень доступа.

В продакшене отдачу файла лучше поручить nginx, чтобы Python не держал соединение:

```nginx
location /protected-media/ {
    internal;
    alias /srv/vershanskaya/protected_media/;
}
```

и включить `PROTECTED_MEDIA_USE_NGINX=True` в `.env`.

## ☎️ Поле телефона

`static/js/phone.js` включается на любом поле с атрибутом `data-phone`.
Первая же цифра превращает поле в `+7 (…`, ведущие `8` и `7` считаются кодом
страны, вставка из буфера разбирается как ручной набор, каретка при правке
середины остаётся на месте. Если скрипт не загрузился, поле работает как
обычное текстовое: номер всё равно приводится к единому виду на сервере
(`users.utils.normalize_phone`), и дубли по телефону не появятся.

## ✅ Тесты

```bash
LOG_LEVEL=WARNING python manage.py test
```

Покрыты вещи, которые ломаются молча и дорого: нормализация телефонов и
склейка дублей, подсчёт архетипа, правила доступа к курсам, отдача видео по
Range, движение лида по воронке только вперёд, двойное бронирование одного
окна, повторные вебхуки об оплате и истечение подписок. Отдельный набор в
`core/tests.py` открывает все публичные страницы — он ловит опечатки в
шаблонах и оборванные `{% url %}`.

## 📦 Деплой

```bash
python manage.py collectstatic --noinput
gunicorn config.wsgi:application --bind 0.0.0.0:8000
```

При `DEBUG=False` включаются HSTS, secure-cookies и редирект на HTTPS —
проверить конфигурацию можно через `python manage.py check --deploy`.
