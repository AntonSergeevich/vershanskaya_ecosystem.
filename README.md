# 🌌 Vershanskaya Ecosystem (powered by S-Poryadok)

> Комплексная веб-экосистема и микро-CRM для эксперта Екатерины Вершанской. Платформа объединяет интерактивное обучение, управление подписками, систему бронирования и автоматизированную воронку продаж.

## 📋 О проекте

Проект разработан для автоматизации рутины, масштабирования бизнес-процессов и бесшовной конверсии трафика в постоянных участников закрытого клуба. Основной упор сделан на архетипическую упаковку смыслов и геймификацию пути пользователя.

### 🧩 Основные модули:
1. **LMS & Платформа обучения (Smart Content)**
   * Разделение контента: Искатель (бесплатно), Творец (клуб), Маг (личное ведение).
   * Загрузка и защита видеофайлов на собственном сервере.
   * Отслеживание прогресса и квиз-воронки (эффект Зейгарник).
2. **CRM и Воронка продаж**
   * Интерактивная Канбан-доска (Новый лид -> Анкета -> Разбор -> Подписка).
   * Умное тегирование пользователей (по архетипам и статусам).
   * Автоматизированные Telegram и SMS рассылки.
3. **Система бронирования (Booking)**
   * Календарный интерфейс управления слотами на 30-минутные разборы.
   * Контроль свободных и занятых окон.
4. **Управление подписками (Membership)**
   * Рекуррентные платежи и автоматический контроль доступа к закрытому клубу.
   * Интеграция с платежными шлюзами.

---

## 🛠 Технологический стек

* **Backend:** Python 3.12+, Django, Django REST Framework.
* **Database:** PostgreSQL (на локалке SQLite для быстрой разработки).
* **Frontend:** React / Alpine.js (API-First подход).
* **Авторизация:** Custom User Model (Telegram ID, Phone Auth).
